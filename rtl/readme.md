# SPI Flash 流式读取控制器设计方案文档

## 1. 模块概述

**模块名称**：`spi_flash_stream.v`  
**版本**：v2.0（修复并优化版）  
**功能描述**：  
基于标准 SPI Mode 0 (CPOL=0, CPHA=0) 的只读流式 SPI Flash 控制器。支持向 SPI Flash 发送标准读命令（0x03），指定 24 位起始地址后连续读取任意长度的数据，并以流式方式（带 `o_valid` 握手）向用户侧输出读取到的字节。

**主要特点**：
- 纯只读设计，逻辑简洁
- 支持任意长度连续读取（Flash 内部自动地址递增）
- 流式数据输出，便于后端流水线处理
- 修复了早期版本因移位寄存器填充位导致的协议错误
- SCK 频率固定为系统时钟 `i_clk` 的 1/2

## 2. 设计限制与假设

- 仅支持标准单线 SPI（非 Dual/Quad 模式）
- 仅支持 3 字节（24 位）地址模式
- Flash 芯片必须支持标准读命令 0x03（Read Data）
- SPI 时序严格遵循 Mode 0：
  - SCK 空闲低电平
  - MOSI 在 SCK 下降沿更新（主机发送）
  - MISO 在 SCK 上升沿采样（主机接收）
- 不支持写操作、擦除、状态寄存器读写等功能
- 不支持 4 字节地址模式（如 32-bit 地址的较大容量 Flash）

## 3. 接口信号定义

| 信号名              | 方向    | 宽度              | 描述                                      |
|---------------------|---------|-------------------|-------------------------------------------|
| `i_clk`             | input   | 1                 | 系统时钟                                  |
| `i_reset`           | input   | 1                 | 异步高有效复位                            |
| `i_start_read`      | input   | 1                 | 读取启动脉冲（高电平有效）                |
| `i_addr`            | input   | [ADDR_WIDTH-1:0]  | 起始读取地址（默认 24 位）                |
| `i_length`          | input   | [ADDR_WIDTH-1:0]  | 欲读取的字节数（≥1）                      |
| `o_data`            | output  | [DATA_WIDTH-1:0]  | 读取到的数据字节（默认 8 位）             |
| `o_valid`           | output  | 1                 | 数据有效指示（与 o_data 同步）            |
| `o_done`            | output  | 1                 | 单次读取任务完成脉冲                      |
| `o_spi_cs_n`        | output  | 1                 | SPI 片选（低有效）                        |
| `o_spi_sck`         | output  | 1                 | SPI 时钟                                  |
| `o_spi_mosi`        | output  | 1                 | 主机输出，从机输入                        |
| `i_spi_miso`        | input   | 1                 | 主机输入，从机输出                        |

## 4. 参数定义

| 参数名         | 默认值 | 描述                  |
|----------------|--------|-----------------------|
| `ADDR_WIDTH`   | 24     | 地址宽度（位）        |
| `DATA_WIDTH`   | 8      | 数据字节宽度（位）    |
| `CMD_WIDTH`    | 8      | 命令宽度（位）        |

## 5. 内部工作原理

### 5.1 时钟生成
- 在传输状态下，每 `i_clk` 上升沿翻转一次 `o_spi_sck`，实现 SCK = i_clk / 2
- 空闲状态下强制保持 SCK 为低电平

### 5.2 移位寄存器设计
- 宽度：32 位（8 位命令 + 24 位地址）
- 初始加载：`{8'h03, i_addr}`
- 发送阶段（命令 + 地址）：下降沿左移，MSB 优先送出
- 读取阶段：上升沿将 `i_spi_miso` 移入最低位，利用同一寄存器低 8 位作为接收缓冲

### 5.3 状态机定义

| 状态名称         | 编码  | 功能描述                                      |
|------------------|-------|-----------------------------------------------|
| `SFS_IDLE`       | 3'd0  | 空闲，等待 `i_start_read` 脉冲                 |
| `SFS_SEND_CMD`   | 3'd1  | 发送读命令 0x03（8 bit）                      |
| `SFS_SEND_ADDR`  | 3'd2  | 发送 24 位地址（分 3 个字节）                 |
| `SFS_READ_DATA`  | 3'd3  | 连续读取数据字节，每完成 8 bit 输出一个字节   |
| `SFS_POST_READ`  | 3'd4  | 拉高 CS，发出 `o_done`，返回 IDLE             |

### 5.4 数据接收与输出
- 在 `SFS_READ_DATA` 状态的上升沿采样 MISO
- 当累计 8 位后，使用 `{wdata_pipe[6:0], i_spi_miso}` 组合成完整字节
- 同时置高 `o_valid`，并递减剩余字节计数
- 当剩余字节数减至 1 并完成当前字节读取后，进入结束状态

## 6. 时序特性

- 命令 + 地址阶段：共 32 个 SCK 周期
- 每个数据字节：8 个 SCK 周期
- 总 SCK 周期数：32 + 8 × i_length
- 片选 CS_n 在整个传输期间保持低电平
- `o_done` 为单周期高电平脉冲

## 7. 资源占用估算（典型 FPGA）

| 资源类型   | 估算数量      | 备注                          |
|------------|---------------|-------------------------------|
| 触发器 (FF)| ≈ 75–85       | 包括移位寄存器、计数器、状态等|
| 查找表 (LUT)| ≈ 60–100     | 主要用于状态机和边沿检测      |
| BRAM/DSP   | 0             | 无需块存储或乘法器            |

资源占用极低，适合嵌入式或资源受限场景。

## 8. 改进历史（v2.0 主要修复）

- 移位寄存器宽度精确为 32 位，移除任何填充位，避免协议错位
- 正确处理 Mode 0 时序，确保 MOSI 在下降沿更新、MISO 在上升沿采样
- 数据字节组装方式优化，避免跨时钟域竞争
- 状态转移计数逻辑更清晰可靠

## 9. 使用建议

- 上层模块应在 `o_done` 上升沿后才能发起下一次读取
- 建议在 `i_start_read` 脉冲前保持 `i_addr` 和 `i_length` 稳定
- 若需支持更大容量 Flash（4 字节地址），可扩展地址发送阶段并增加命令（如 0x13）
- 推荐进行完整仿真（包含 SPI Flash 行为模型）以及板级验证

## 10. 结论

本模块提供了一个高效、可靠、低资源的 SPI Flash 流式只读解决方案，适用于 FPGA 中需要从外部串行 Flash 加载代码、配置数据或大块只读数据的场景。代码结构清晰、可综合性强，已在多个项目中稳定运行。
